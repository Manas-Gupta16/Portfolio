## 🏃 Running Locally

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

---

## 🚢 Deployment

This site is built with [Astro](https://astro.build) and can be deployed to [Vercel](https://vercel.com) in one click:

1. Push to GitHub (already done ✅)
2. Go to [vercel.com](https://vercel.com) → New Project → Import `Manas-Gupta16/Portfolio`
3. Click **Deploy**
