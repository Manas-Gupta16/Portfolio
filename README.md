# Manas Gupta — Portfolio

Personal portfolio website built with Astro, React & TailwindCSS.

🌐 **Live:** [manas-gupta16.github.io/Portfolio](https://manas-gupta16.github.io/Portfolio/)

---

## Running Locally

```bash
cd dark-minimal-1.0.0/dark-minimal-1.0.0
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.
